## Projenin Amacı ve Kısa Açıklaması

KrediZeka, bireylerin kredi başvurusu yapmadan önce kendi finansal risklerini ölçmelerini sağlayan, yapay zekâ destekli modern bir web uygulamasıdır.

Türkiye'de her yıl milyonlarca kredi başvurusu yapılmakta, ancak başvuruların önemli bir kısmı ön değerlendirme aşamasında reddedilmektedir. KrediZeka bu sorunu dört adımda çözer:

1. **Anlık Risk Skoru** — Kullanıcının gelir, borç, kredi tutarı, yaş, kredi geçmişi ve birikim bilgilerine göre 0–100 arası onaylanma skoru üretilir.
2. **Açıklanabilir Yapay Zekâ (XAI)** — SHAP TreeExplainer ile her skor için hangi faktörlerin pozitif/negatif yönde etki ettiği şeffaf şekilde gösterilir.
3. **Finansal Oran Analizi** — DTI (Borç/Gelir) ve LTI (Kredi/Gelir) oranları sektör standartlarıyla karşılaştırılır.
4. **Kişiselleştirilmiş Tavsiye** — Kural tabanlı bir motor, kullanıcının profiline özgü Türkçe öneriler sunar.

### Öne Çıkan Özellikler

- **XGBoost ML Modeli** — %98.75 doğruluk oranı, GridSearchCV ile hiperparametre optimizasyonu
- **SHAP Açıklanabilirlik** — Her tahmin için en etkili faktörlerin yatay bar grafikle görselleştirilmesi
- **3 Adımlı Sihirbaz Form** — Kişisel Durum → Finansal Veriler → Sonuç
- **12 İnteraktif Finansal Modül** — Bireysel, Ticari ve Ürünler sekmelerinde simülasyon motorları
- **ZekaBot — Yapay Zekâ Asistanı** — Google Gemini API destekli 7/24 finansal sohbet asistanı
- **PostgreSQL + SQLAlchemy** — İlişkisel veri katmanı (users + 3 analiz tablosu, JSONB sütunlar)
- **Docker Compose** — 3 servis (veritabanı / backend / frontend) tek komutla ayağa kalkar
- **PWA Desteği** — Service Worker + Web App Manifest ile telefona kurulabilen uygulama
- **Karanlık Tema** — Tailwind class-based dark mode, sistem tercihi algılama
- **Çoklu Dil (i18n)** — react-i18next ile tam Türkçe/İngilizce çeviri
- **PDF Rapor** — Analiz sonucunu A4 belge olarak indirme
- **E-posta Doğrulama ve Şifre Sıfırlama** — Brevo ile güvenli token tabanlı akışlar
- **Rate Limiting** — IP tabanlı brute-force koruması (slowapi)
- **Rol Tabanlı Erişim (RBAC)** — Yönetici paneli ve `is_admin` rolü
- **Redis Önbellekleme** — fastapi-cache2 ile (Redis yoksa bellek-içi yedek)

## Kurulum Adımları

### Ön Gereksinimler

- **Python 3.11+**
- **Node.js 18+** ve **npm**
- **Docker & Docker Compose** (opsiyonel — önerilen yöntem)
- **Git**

### Yöntem 1: Docker Compose (Önerilen)

Tüm sistem (PostgreSQL + FastAPI + React/Nginx) tek komutla ayağa kalkar:

```bash
# 1. Repoyu klonla
git clone https://github.com/olcays20/kredizeka.git
cd kredizeka

# 2. Ortam değişkenlerini hazırla
cp .env.example .env

# 3. Tüm servisleri başlat
docker compose up --build
```

### Yöntem 2: Yerel Geliştirme (Docker'sız)

**Backend:**
```bash
cd backend
python -m venv venv
venv\Scripts\activate              # Linux/Mac: source venv/bin/activate
pip install -r requirements.txt
python train_model.py              # ML modelini eğit (~1-2 dakika)
uvicorn main:app --reload --port 8000
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

### Önemli Ortam Değişkenleri

| Değişken | Açıklama |
|---|---|
| `DATABASE_URL` | PostgreSQL bağlantı adresi (tanımlı değilse SQLite'a düşer) |
| `CORS_ORIGINS` | İzinli origin listesi (virgülle ayrılır) |
| `GEMINI_API_KEY` | ZekaBot için Google Gemini anahtarı (opsiyonel) |
| `BREVO_API_KEY` | E-posta gönderimi için Brevo anahtarı (opsiyonel) |
| `DEFAULT_ADMIN_PASSWORD` | İlk yönetici parolası |

> **Not:** Tüm API anahtarları opsiyoneldir — tanımlı değilse ilgili özellik güvenli bir yedek davranışa geçer (örn. Gemini yoksa anahtar kelime tabanlı asistan, Brevo yoksa e-posta simülasyonu).

### Erişim Noktaları

### Kullanım Adımları

1. **Kayıt Ol** — TC Kimlik No, ad-soyad, e-posta ve şifre ile hesap oluştur
2. **Giriş Yap** — TC Kimlik No ve şifre ile oturum aç
3. **Risk Analizi** — Ana sayfadaki 3 adımlı formu doldur (Kişisel → Finansal → Sonuç)
4. **Sonuç** — 0–100 arası risk skoru, SHAP açıklamaları, DTI/LTI oranları ve kişisel tavsiyeleri gör
5. **PDF İndir** — Analiz sonucunu A4 rapor olarak indir
6. **Hizmet Modülleri** — Bireysel, Ticari veya Ürünler sekmelerinden interaktif simülasyonları kullan
7. **ZekaBot** — Sağ alt köşedeki sohbet balonuna tıklayarak finansal sorularını sor
